# 🏔️ Nepal Tours & Travels

A travel website to explore and book tours across Nepal.

## Pages
- Home — Browse & book tour packages (Kathmandu, Pokhara, Chitwan)
- Explore— Photo gallery of Nepal's culture & landscapes
- FAQs — Searchable frequently asked questions
- Login/Signup — User authentication page
- Payment — Choose from eSewa, Khalti, or Fonepay
## Ways to run it.
1. Download the project folder
2. Make sure `images/` and `photo/` folders are included
3. Open `index.html` in a browser — done!
